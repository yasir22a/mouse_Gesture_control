Hand Gesture Control & Scrolling System
Overview

A vision-based system that detects hand gestures using OpenCV and Python to control mouse movement and scrolling. It enables a touch-free, intuitive interaction with your computer in real-time.

Features

Move the cursor with hand gestures

Scroll up and down

Real-time webcam interaction

Easy to use and lightweight

Technology Used

Programming Language: Python

Libraries: OpenCV, Mediapipe, PyAutoGUI, numpy, time 


Hardware: Standard Webcam

How It Works

The webcam captures live hand movements.

OpenCV detects hand landmarks.

Specific gestures are mapped to cursor and scrolling commands.

Actions are executed in real-time on your computer.

Applications / Uses

Touch-free computer navigation

Presentation control without a mouse

Gaming and creative applications

Accessibility for users with limited mobility

Installation / Setup
# Clone the repository
git clone <https://github.com/yasir22a/mouse_Gesture_control/>

# Install dependencies
pip install opencv-python mediapipe pyautogui,numpy, time

# Run the project
python hand_gesture_control.py
